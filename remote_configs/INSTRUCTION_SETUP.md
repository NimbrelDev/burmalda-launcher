# Инструкция по настройке удаленных обновлений и объявлений (GitFlic / Codeberg)

В лаунчере реализована отказоустойчивая система проверки версий, принудительной блокировки устаревших сборок и рассылки объявлений игрокам. Она использует два зеркала: основное российское (GitFlic) и резервное (Codeberg).

---

## 1. Как работает система

При каждом запуске лаунчер запрашивает два файла:
1. `version.json` — данные об актуальной и минимально поддерживаемой версии.
2. `broadcast.json` — объявление игрокам (если файла нет или он возвращает 404, никакого объявления не показывается).

Если интернет недоступен или репозиторий временно не отвечает, лаунчер **не блокирует** игру оффлайн, а дает спокойно запустить установленную версию.

---

## 2. Создание репозитория и размещение файлов

### Вариант А: GitFlic (Российский хостинг)
1. Зарегистрируйтесь на [gitflic.ru](https://gitflic.ru) и создайте **публичный** репозиторий, например `burmalda-launcher` (или любое ваше название).
2. Загрузите в корень репозитория файл `version.json`.
3. Чтобы получить прямую сырую ссылку (raw), откройте файл `version.json` на GitFlic и скопируйте ссылку с кнопки «Сырой файл» (или добавьте `blob/raw?file=version.json`).
4. Формат ссылки:
   ```
   https://gitflic.ru/project/<логин>/<репозиторий>/blob/raw?file=version.json
   ```

### Вариант Б: Codeberg (Европейский независимый хостинг)
1. Зарегистрируйтесь на [codeberg.org](https://codeberg.org) и создайте публичный репозиторий `burmalda-launcher`.
2. Загрузите файлы в ветку `main`.
3. Прямая сырая ссылка имеет вид:
   ```
   https://codeberg.org/<логин>/<репозиторий>/raw/branch/main/version.json
   ```

> Примечание: В файле `desktop/main.js` эти адреса уже прописаны в массиве `UPDATE_CONFIG_URLS` и `BROADCAST_CONFIG_URLS`. При необходимости вы можете изменить логин и репозиторий на ваши реальные данные.

## 3. Сценарии использования `version.json`

### Сценарий 1: Обычный режим (все актуально)
```json
{
  "latestVersion": "1.0.0",
  "minSupportedVersion": "1.0.0",
  "downloadUrl": "https://burmalda-hub.ru",
  "title": "Доступно обновление",
  "message": "Вышла новая версия лаунчера!",
  "blockedTitle": "ВЕРСИЯ УСТАРЕЛА",
  "blockedMessage": "Данная версия лаунчера больше не поддерживается."
}
```
- Игроки с версией 1.0.0 заходят и играют без лишних окон.

### Сценарий 2: Вышла новая версия 1.0.1, но старые еще работают (мягкое уведомление)
```json
{
  "latestVersion": "1.0.1",
  "minSupportedVersion": "1.0.0",
  "downloadUrl": "https://burmalda-hub.ru/download",
  "title": "Доступно обновление 1.0.1",
  "message": "Мы добавили новые шейдеры и ускорили загрузку. Скачайте обновление на сайте!"
}
```
- У игроков с версией 1.0.0 появится аккуратное окно с предложением перейти на сайт и кнопкой «Позже». Играть при этом можно.

### Сценарий 3: Блокировка старых версий (Kill-Switch)
Если в старой версии обнаружился критический баг, читы или несовместимость с сервером, вы просто меняете `minSupportedVersion`:
```json
{
  "latestVersion": "1.0.2",
  "minSupportedVersion": "1.0.2",
  "downloadUrl": "https://burmalda-hub.ru/download",
  "blockedTitle": "ВЕРСИЯ ЗАБЛОКИРОВАНА",
  "blockedMessage": "Версия 1.0.0 и 1.0.1 заблокирована из-за обновления защиты. Скачайте версию 1.0.2 на сайте."
}
```
- У всех игроков со старой версией лаунчер **полностью блокируется**: окно нельзя закрыть, кнопка «В БОЙ» отключается, доступна только кнопка «СКАЧАТЬ ОБНОВЛЕНИЕ», открывающая сайт в браузере.

## 4. Сценарии использования `broadcast.json` (Объявления игрокам)

### Как отправить объявление:
1. Загрузите файл `broadcast.json` в репозиторий:
```json
{
  "id": "notice_tournament_1",
  "title": "ТУРНИР В СУББОТУ",
  "message": "В субботу в 18:00 по МСК стартует турнир по BedWars! Призовой фонд 10 000 рублей. Регистрация в нашем Telegram.",
  "buttonText": "Записаться в Telegram",
  "buttonUrl": "https://t.me/burmalda",
  "canClose": true
}
```
- Каждый игрок при запуске увидит это окно. После закрытия окно не будет надоедать в рамках этой же сессии (запоминается по `id`).
- Если поменять `id` (например, на `notice_tournament_2`), окно покажется снова с новым текстом.

### Как отключить объявление:
- Просто **удалите** файл `broadcast.json` из репозитория (или очистите его содержимое). Лаунчер получит 404/пустоту и перестанет показывать объявление.

---

## 5. Чек-лист перед первым релизом (v1.0.0)

1. **Версия приложения:** в `package.json` установлена `1.0.0`.
2. **Сайт скачивания:** убедитесь, что ссылка `downloadUrl` в `version.json` ведет на вашу реальную страницу скачивания.
3. **Хранилище настроек:** все пользовательские данные сохраняются в `~/.zenith-launcher` (настройки, сборки, моды, скины).
4. **Сборка установщика:**
   - Для сборки исполняемых файлов под Windows и Linux используйте `npm run build` или `electron-builder`.
